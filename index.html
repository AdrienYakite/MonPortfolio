Mes projets Front-end

Mon but d'ici à l'été 2024 est de réaliser un total de cinq projets web, structurés de la sorte : un site web uniquement en HTML&CSS (sans l'aide d'un framework), un site web centré autour de JavaScript (sans framework), un site web HTML&CSS et JavaScript (toujours sans framework) et enfin un projet web complet s'appuyant sur une API et construit à l'aide de React.
Organiser mes projets ainsi me permet de démontrer ma maîtrise de ces différents langages et outils indépendamment les uns des autres.


Voici donc les quelques sites et applications web (sans compter ce site Portfolio) sur lesquels j'ai pu travailler entre Octobre 2023 et aujourd'hui :

AzerType, l'application pour taper plus vite !

AzerType est une application web d'entraînement à la dactylographie. Je l'ai réalisée uniquement en JavaScript, HTML et CSS sans framework. L'application prend la forme d'un petit jeu ou le but est de recopier sans faute les mots ou les phrases proposées. Le joueur peu par la suite partager son score avec un ami par mail. LesBonnesPieces, site de vente de pièces auto

LesBonnesPieces est un site de vente de pièces automobile au détail. Il est possible d'y consutler un catalogue de pièces détachées accompagnées de leur description, prix ou encore disponnibilité ainsi que d'y retrouver les avis de clients. Le site focntionne à l'aide d'une API en ligne.
La version actuelle récupère les pièces via un fichier JSON et non pas une API car je travaille actuellement dessus et ai des problèmes à régler. Pour cette raison les avis client (stockés sur l'API) ne sont pas à l'heure actuelle disponibles. La situation devrait être réglée sous peu.
